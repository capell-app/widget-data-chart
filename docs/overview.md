# Data Chart Widget

<!-- prettier-ignore-start -->

## What it does

Data Chart turns small editorial datasets into bar, line, or donut charts without a client charting service. Each chart is rendered server-side and paired with a complete accessible data table.

## Do I need to do anything?

Add the widget to a page in Layout Builder, complete its fields, and preview the public page before publishing.

## Where it shows up

In Layout Builder, as a Data Chart widget for labels, up to eight series, up to 50 points, chart type, and presentation options.

## Good to know

- This free beta extension belongs to Capell Foundation and requires Layout Builder.
- SVG titles, labels, patterns, and the HTML table keep meaning available without relying on colour alone.
